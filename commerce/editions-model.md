# Editions Model

Habitat Sol can support both free public storytelling and selected collectible editions.

## Public layer

- Daily image and story post.
- Archive organized by sol, character, location, and theme.

## Collector layers

| Tier | Description |
|---|---|
| Digital collector edition | High-resolution file, certificate/provenance, optional minting. |
| Physical print | Limited signed/numbered archival print. |
| Seasonal collection | Curated set of episodes from a narrative arc. |
| Yearbook | Printed anthology of the first 365 sols. |

## NFT positioning

Avoid making NFTs the headline. Prefer language such as:

> Digital provenance editions available for selected works.

NFT minting can remain an optional mechanism for collectors who want it.
