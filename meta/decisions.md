# Decisions

This file records important canon and production decisions.

## 2026-07-21 — Project name

Decision: The project is named **Habitat Sol**.

Rationale:

- Sol means sun, suggesting origin and first light.
- A sol is a Martian day, matching the daily episode structure.
- Habitat Sol feels like a bureaucratic early settlement designation that became a beloved town name.

## 2026-07-21 — Tagline

Decision: Use the tagline:

> Before Mars had cities, it had a town.

## 2026-07-21 — Settlement naming convention

Decision: Early permanent settlements use the naming convention:

> Habitat + singular Latin-root or symbolic noun

Canonical initial set:

- Habitat Sol,
- Habitat Meridian,
- Habitat Elysium,
- Habitat Ferrum,
- Habitat Astra,
- Habitat Arcadia.

## 2026-07-21 — Core cast structure

Decision: The project begins with two neighboring families in Habitat Sol:

- the hetero Varga-Sato family,
- the LGBTQ Okonkwo-Reyes family.
