# Habitat Sol

**Before Mars had cities, it had a town.**

Habitat Sol is a daily visual fiction archive set in the first permanent civilian settlement on Mars.

Each entry pairs a generated image with a short story: a glimpse into ordinary life inside an extraordinary place. The project follows two neighboring families as they work, love, grieve, argue, raise children, grow food, repair machines, and try to remain human in a world that was never built for them.

This repository is the open world bible and production archive for the Habitat Sol universe. Canon, characters, settlements, locations, image workflows, episode metadata, and production notes are tracked here as the world evolves.

## Core setting

The story begins in **Habitat Sol**, the oldest Martian settlement: population roughly **2,000**. Once humanity's first permanent civilian habitat, it is now a historic town in a wider Martian civilization of capitals, industrial cities, research settlements, agricultural zones, and wealthy metropolises.

Sol is intimate, worn, civic-minded, proud, and increasingly unsure of its place in the future.

## Project format

The public work is intended as a daily gallery/fiction rhythm:

- one image,
- one short story,
- one sol,
- recurring characters,
- evolving canon,
- selected pieces available as physical and/or digital editions.
