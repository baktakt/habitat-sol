# ComfyUI Production Notes

This folder tracks workflows, prompt templates, character references, location references, and reproducibility notes for Habitat Sol image generation.

## Workflow families

1. **Character identity workflows** — stable portraits, full-body references, expression sheets, clothing variations.
2. **Family/group workflows** — recurring group compositions and neighbor scenes.
3. **Location workflows** — reusable visual sets for Sol interiors/exteriors.
4. **Episode workflows** — one-off art pieces using character and location references.

## Production principle

Every final image should preserve:

- character recognizability,
- location continuity,
- documentary/lived-in visual style,
- episode-specific emotional tone.

## Metadata to keep

- prompt,
- negative prompt,
- model/checkpoint,
- LoRAs or reference images,
- seed,
- resolution,
- denoise/settings,
- upscaler,
- final selected image path,
- publication/edition status.
